# 🌙 就寝カウントダウン

夜更かし防止のための、就寝予定時刻までのカウントダウンタイマーアプリです。

## 🔗 デモ

**➡️ https://miz0ken.github.io/bedtime-countdown/**

---

## 📖 アプリの説明

「気づいたら深夜2時…」を防ぐために作りました。

就寝予定時刻を設定すると、残り時間を大きなネオン文字でカウントダウン表示します。
時間が来てもベッドに入っていなければ「早く寝ましょう🌙」と警告してくれます。

---

## ✨ 主な機能

- ⏱️ **カウントダウン表示** — 就寝予定時刻まであと何時間何分何秒かをリアルタイム表示
- 💾 **時刻の記憶** — 設定した就寝時刻を localStorage に保存し、次回も引き継ぎ
- 🌃 **自動ダークモード** — 19時以降は背景が黒〜紺のダークテーマに切り替わる
- 🟢 **ネオン発光デザイン** — カウントダウンの数字が緑色（#39ff14）に発光する
- ⚠️ **就寝時刻を過ぎたら警告** — 時刻を過ぎると「早く寝ましょう🌙」を6時間表示
- 📱 **レスポンシブ対応** — スマホでも PC でも崩れないレイアウト

---

## 🚀 使い方

1. **デモURLを開く** → https://miz0ken.github.io/bedtime-countdown/
2. 画面右下の **⚙ ボタン** をタップ
3. 就寝したい時刻を入力して **「保存」** を押す
4. あとは画面を見ながら時間を意識するだけ！

> デフォルトの就寝予定時刻は **AM 1:00** です。

## 💡 開発のきっかけ

プログラミング学習中に「自分が本当に使いたいものを作ろう」と考えて作りました。

夜更かしが続いていたので、常にブラウザで開いておける就寝リマインダーがほしくなったのがきっかけです。
シンプルな構成（HTML + JS のみ）なので、学んだことを素直に形にできた最初のアプリです。
